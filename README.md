## Sistema de Monitoramento de Quedas para Idosos

Este projeto propõe o desenvolvimento de um sistema de monitoramento contínuo de movimentos para idosos, com foco na detecção de quedas e envio de alertas remotos aos responsáveis. A iniciativa surge da necessidade de ampliar a segurança da população idosa, especialmente em contextos onde há riscos de quedas, uma das principais causas de internações na terceira idade.

O sistema utiliza:

- Microcontrolador ESP32
- Sensores de movimento
- Comunicação via Wi-Fi
- Programação em C++
- Utilização de Bot do Telegram
- Simulação e testes na plataforma Wokwi

A solução foi validada por meio de simulações digitais, permitindo testar cenários de movimentação e quedas antes da implementação física do protótipo. O projeto combina pesquisa teórica sobre envelhecimento e tecnologia assistiva com desenvolvimento prático de um sistema acessível, de baixo custo e eficiente energeticamente. O objetivo final é contribuir para soluções tecnológicas que promovam maior segurança, autonomia e qualidade de vida para a população idosa.
